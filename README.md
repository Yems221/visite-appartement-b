# Visite Appartement B

Visite 3D libre d'un appartement de 3 pièces (92,66 m², 6e étage) à Dakar, construite à partir du plan PDF de l'architecte.

Le plan s'ouvre comme une feuille d'architecte. On clique sur « Entrer », les murs montent, puis on visite librement : clavier et souris sur ordinateur, deux joysticks sur téléphone. Chaque pièce passe du dessin au trait aux vraies matières quand on y entre.

- Rendu temps réel : three.js 0.170, fichiers statiques, sans étape de build.
- `?walk` dans l'URL saute l'introduction et démarre sur le palier.
- Bouton **Réseaux** (touche R) : mode rayons X avec l'électricité, l'eau froide, l'eau chaude et les évacuations, et 3 points à vérifier. **Ce réseau est fictif**, dessiné pour la démonstration : il ne correspond à aucun plan technique réel.
